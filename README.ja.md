# The Booha Adventure

*[English version here](README.md)* · [Booha Worldを見る ↗](https://booha-adventure-studios.github.io/booha-world/)

The Booha Adventureは、英語学習・物語の探索・ミニゲーム・進捗の保存を、ひとつの不思議な世界の中でまとめて体験できる、ブラウザベースの学習アドベンチャーです。

短いセッションで区切って遊びたい学習者、はっきりとした視覚・音声のフィードバックを求める学習者、そして「また明日も遊びたい」と思える理由を求める学習者のために作られています。

## プレイヤーができること

- Booha Adventureの迷路を探索する
- Karasuki、Utsuroba、Muenbaなどの物語世界を訪れる
- 単語、文章、リスニング、リーディング、スペリング、読解の練習をする
- Boohaのキャラクターたちを主役にした短いボーナスゲームで遊ぶ
- ストーリーシーン、コレクション、キャラクタープロフィール、冒険の進捗をアンロックする
- Webアプリとして、またはインストール可能なプログレッシブウェブアプリ(PWA)として利用する

## 教育としての考え方

このプロジェクトは、いくつかのシンプルな考え方の上に成り立っています。

- 練習は「アドベンチャーの一部」のように感じられるべき
- 短く、繰り返せる活動の方が、また戻ってきやすい
- 間違いは体験を終わらせるものではなく、役に立つフィードバックであるべき
- 物語・音・アートワーク・言語練習は、互いを支え合うべき
- 進捗は、個人的で目に見えるものであるべき

## 技術概要

The Booha Adventureは、意図的にフレームワークを使わない軽量なWebアプリケーションとして、次の技術で構築されています。

- HTML
- CSS
- Vanilla JavaScript(素のJavaScript)
- JSONベースのカリキュラム・ストーリーコンテンツ
- HTML5のオーディオ・ビデオ
- Web Audio APIによる音響効果
- プログレッシブウェブアプリ(PWA)機能
- キャッシュとオフライン対応のためのService Worker
- 認証されたアクセスとプレイヤーの進捗管理のための外部サービス

このプロジェクトは、フロントエンドフレームワークやバンドラーを必要としません。

## リポジトリ構成

```text
index.html              メインのエントリーポイント
maze.html               アドベンチャーの迷路とワールドナビゲーション
curriculum/             カリキュラムのハブと学習アクティビティ
content/                ストーリーと学習コンテンツ
games/                  再利用可能な言語ゲームのモジュール
js/                     アプリケーションロジックと共有システム
theme/                  ページとゲームのスタイル
assets/                 アートワーク、オーディオ、ビデオ
tests/                  コンテンツと動作を自動でチェックするテスト群
verify.sh               デプロイ前の検証スクリプト
```

`karasuki.html`、`muenba.html`、`liar_machine.html`など、各ワールド・各ゲームのページは、`index.html`や`maze.html`と同じくリポジトリのルートに、1体験につき1ファイルの形で置かれています。

## ローカル開発

このプロジェクトは静的なWebアプリケーションです。開発・テスト用に、小さなローカルプレビューサーバーが同梱されています。

```bash
node tests/serve-preview.cjs
```

起動後、以下を開いてください。

```
http://localhost:8127/index.html
```

## 検証(Verification)

デプロイ前には、以下を実行してください。

```bash
./verify.sh
```

この検証スイートは、コンテンツデータ、ナビゲーションの整合性、ゲームの動作、Service Workerのパス、メディアアセット、レスポンシブ対応、パフォーマンスに関する安全対策をチェックします。

完全な検証を実行するには、Node.jsとPython 3に加えて、メディア検証に使用するffmpeg(ffprobeを含む)が必要です。

## プロジェクトの状況

The Booha Adventureは、現在も活発に開発が続いている教育・創作プロジェクトです。新しいエリア、キャラクター、ストーリー、ゲーム、学習アクティビティは、今後も順次追加されていきます。

プロジェクトの成長にともない、インターフェース、コンテンツ、内部システムは変更される場合があります。
