# The Booha Adventure

*[English version here](README.md)* · [Booha Worldを見る ↗](https://booha-adventure-studios.github.io/booha-world/)

The Booha Adventureは、日本の学習者のためのブラウザベースの英語学習アドベンチャーです。毎週のカリキュラム練習、物語の世界、ミニゲーム、進捗の保存を、ひとつの不思議な世界の中でまとめて体験できます。

短いセッションで区切って遊びたい学習者、はっきりとした視覚・音声のフィードバックを求める学習者、そして「また明日も遊びたい」と思える理由を求める学習者のために作られています。

*最終更新：2026-10-25*

## プレイヤーができること

- **毎週のカリキュラムを遊ぶ。** その週のレッスン内容から作られた9つの短いゲームが、3つのレーンに分かれています。
  - **Words(単語)：** Vocab Tap、Spell the Word、Vocab Speed
  - **Sentences(文章)：** Sentence Tap、Sentence Order、Sentence Speed
  - **Listen(リスニング)：** Say a Word、Say a Sentence、Ask a Sentence
- **コースを選ぶ。** 3つのカリキュラムが同じゲームシステムを共有しています：Pre-Boo(年少の学習者向け・ひらがな対応)、Boo-riculum、Boo-Continuum。
- **毎週のトレイルを進む。** ゲームごとの星で、となり合うゲームの間の道が光ります(+1★のつながりボーナス)。9つすべてで★★を取るとアーケードの宝箱が開き、3つのBlitzをクリアするとその週のBoohaスキンが手に入ります。すべて毎週日曜日(東京時間)にリセットされます。
- **ボーナスゲームに挑戦する。** Booha Bites(抜けた言葉を見つける)、Echo(聞いて書く)、Week Boss(9つのゲームをすべて遊ぶと開く、まとめのボス戦)。ボーナスゲームは9ゲームのアンロック条件には影響しません。
- **物語の世界を探索する：**
  - **Karasuki：** ハブとなる世界。それぞれに物語を持つ、集められるキャラクターたち「Wanderers」が住んでいます。
  - **Grimmerglen：** 失われた記憶の家。段階的なタイピング(選択肢 → ヒント → 記憶をまるごと思い出す)で記憶を取り戻します。
  - **Utsuroba：** 読解を中心としたエピソード(順番・詳細・推論の課題)とDrifterのクエスト。中には静かな学習スペース「Akiya(Family Room)」があります。
  - **Muenba：** ブリーフィング、ゴースト探し、隠れること、読解のゲートがある幽霊の墓地。
  - **Mister Happy's House：** Liar Machine(1台の端末を交代で使う2人プレイ)とSnap Test。
- **アーケードゲームをアンロックする：** Booha Invaders、Booha Blocks、Booha Destruction、Feed Booha。
- **プロフィールを育てる：** レベルとランクコイン、8つのウィークリーメダル(ブロンズ・シルバー・ゴールド)、ずっと残るAdventure Tokens、Wandererのコレクション、ぼうけんカレンダー。
- **English Juku(塾の生徒向け)：** ディクテーション、自由記述の翻訳、ライティング、リーディングを行う教室用のレッスンモードと、週ごとのレポート。
- **インストールする：** オフラインキャッシュ付きのWebアプリ(PWA)として利用できます。

## 教育としての考え方

アプリが実際に使っている仕組みは次のとおりです。

- **思い出す練習(リトリーバル)。** 選ぶだけでなく、答えを自分で作ります(単語や文章をタイプする、並べる、聞いて選ぶ)。Grimmerglen、Echo、Week Bossでは記憶から思い出すことが求められます。
- **一回目の正解を重視し、やり直しも認める。** 一回目で正解すると満点とコンボが得られます。当てずっぽうが得にならないゲームでは、直した答えにも部分点があります。間違えてもフィードバックがあり、ゲームは続きます。
- **スピードではなく準備を評価する。** 「Ready pace(じゅんび OK)」のレインボースターは、ほとんどの答えが一回目で正解し、落ち着いたペースで答えられたときにもらえます。答えにかかった時間の中央値を使うため、ノートを確認するために止まっても失われません。あわてた連打は対象外です。スピード系のゲームでは正確さだけを見ます。
- **短い一週間のサイクル。** 内容はカリキュラムの週ごとにまとまっています。進捗、メダル、ボーナスの目標は毎週日曜日にリセットされ、毎週が新しいスタートになります。一方で、トークンやじゅんびの記録、コレクションなどの永続的な記録は引き継がれます。
- **レベルに合わせた日本語サポート。** 説明は日英の2言語です。Pre-Booはひらがな、上のコースは漢字とふりがなを使います。
- **目に見える、自分だけの進捗。** 星、つながり、レーンごとの内訳(「Words 2/3 · Sentences 1/3 · Listen 1/3」)、自己ベストの週が、次にやることをはっきり示します。
- **低いプレッシャー。** ゲームはあくまで練習です。Jukuでは、ゲームの結果が学習の証拠として使われたり、点数を変えたりすることはありません。

## プライバシーと生徒のデータ

- 生徒の情報は**名と姓のみ**です。姓はアプリのどこにも表示されず、スクールのサーバー(Wix)にだけ保存されます。
- 進捗は**生徒ごとに**保存されます(スクールのサーバーと同期し、ブラウザにも保存)。1台のiPadを共有しても、お互いの進捗が見えたり影響したりすることはありません。
- **先生や保護者向けのダッシュボードはありません。** 進捗を見るには、生徒本人の端末を見るか、その生徒のPINが必要です。これは意図的な設計です。
- アプリには**広告も、サードパーティの解析スクリプトも含まれていません**。

## 技術概要

The Booha Adventureは、意図的にフレームワークを使わない軽量なWebアプリケーションとして、次の技術で構築されています。

- HTML、CSS、Vanilla JavaScript(素のJavaScript。フレームワークもバンドラーも不要)
- JSONベースのカリキュラム・ストーリーコンテンツ
- HTML5のオーディオ・ビデオと、Web Audio APIによる音響効果
- プログレッシブウェブアプリ(PWA)機能と、キャッシュ・オフライン対応のためのService Worker
- スクール独自のバックエンドを通じた、認証されたアクセスと生徒ごとの進捗同期

**対応端末：** 古いiPadを主な対象としています。画像は明確なサイズ予算に従い([PERFORMANCE-BUDGETS.md](PERFORMANCE-BUDGETS.md))、アニメーションはtransformとopacityのみを使い、動きを減らす設定や遅い端末では演出が控えめになります。

## リポジトリ構成

```text
index.html              メインのエントリーポイント
maze.html               アドベンチャーの迷路とワールドナビゲーション
game.html               9つのカリキュラムゲームとボーナスゲームの共通ページ
profile.html            生徒のプロフィール：トレイル、メダル、トークン、記録
curriculum/             カリキュラムのハブ(コースごとのゲーム・学習メニュー)
content/                毎週のレッスンデッキと物語コンテンツ
games/                  ゲームエンジン(9つのカリキュラムゲーム+ボーナスゲーム)
js/                     アプリケーションロジックと共有システム(js/core/ ＝ セーブ、スコア、アンロック、トークン)
theme/                  ページとゲームのスタイル
assets/                 アートワーク、オーディオ、ビデオ
tests/                  コンテンツと動作を自動でチェックするテスト群
tools/                  メンテナンス用ツール(例：Ready paceの調整に使う pace-report.cjs)
verify.sh               デプロイ前の検証スクリプト
```

`karasuki.html`、`muenba.html`、`liar_machine.html`など、各ワールド・各ゲームのページは、`index.html`や`maze.html`と同じくリポジトリのルートに、1体験につき1ファイルの形で置かれています。

設計メモ：[PERFORMANCE-BUDGETS.md](PERFORMANCE-BUDGETS.md)、[JUKU-ASSESSMENT-DESIGN.md](JUKU-ASSESSMENT-DESIGN.md)、[family-room-design-lock.md](family-room-design-lock.md)。AIツール向けのテキスト版の案内は[llms.txt](llms.txt)にあります。

## ローカル開発

このプロジェクトは静的なWebアプリケーションです。開発・テスト用に、小さなローカルプレビューサーバーが同梱されています。

```bash
node tests/serve-preview.cjs
```

起動後、以下を開いてください。

```
http://localhost:8127/index.html
```

## 検証(Verification)

デプロイ前には、以下を実行してください。

```bash
./verify.sh
```

この検証スイート(約300項目)は、コンテンツデータ、ナビゲーションの整合性、ゲームの動作、スコアとセーブのルール、週の切り替わり、Service Workerのパス、メディアアセット、レスポンシブ対応、パフォーマンス予算をチェックします。

完全な検証を実行するには、Node.jsとPython 3に加えて、メディア検証に使用するffmpeg(ffprobeを含む)が必要です。

## プロジェクトの状況

The Booha Adventureは、現在も活発に開発が続いている教育・創作プロジェクトです。新しいエリア、キャラクター、ストーリー、ゲーム、学習アクティビティは、今後も順次追加されていきます。

プロジェクトの成長にともない、インターフェース、コンテンツ、内部システムは変更される場合があります。
